# VKU · Lập trình ứng dụng di động

**Bộ sưu tập bài thực hành Android với Jetpack Compose**

[![Kotlin](https://img.shields.io/badge/Kotlin-7F52FF?style=for-the-badge&logo=kotlin&logoColor=white)](https://kotlinlang.org)
[![Jetpack Compose](https://img.shields.io/badge/Jetpack_Compose-4285F4?style=for-the-badge&logo=jetpackcompose&logoColor=white)](https://developer.android.com/jetpack/compose)

> Tổng hợp 8 ứng dụng Android được xây dựng bằng **Kotlin** và **Jetpack Compose**, từ giao diện cơ bản đến quản lý trạng thái, điều hướng, Cloud Firestore và Firebase Authentication. *(Lab 1 là bài làm quen công cụ, không có mã nguồn ứng dụng.)*

## Danh sách bài thực hành

| Lab | Ứng dụng | Nội dung chính | Chi tiết |
|:---:|----------|----------------|----------|
| 2 | Business Card | Layout cơ bản: `Column`, `Row`, `Image`, `Icon` | [Xem chi tiết](README_LAB_2.md) |
| 3 | Dice Roller | State & sự kiện: `remember`, `mutableIntStateOf`, `Button` | [Xem chi tiết](README_LAB_3.md) |
| 4 | Tip Calculator | State hoisting, `TextField`, `Switch`, tính toán | [Xem chi tiết](README_LAB_4.md) |
| 5 | Woof | Material 3 Theming: Color Scheme, Typography, Shape, Dark Theme | [Xem chi tiết](README_LAB_5.md) |
| 6 | Cupcake | Navigation Compose, ViewModel, StateFlow, đặt hàng | [Xem chi tiết](README_LAB_6.md) |
| 7 | Firebase CRUD | Cloud Firestore: Thêm / Đọc / Sửa / Xóa, `addSnapshotListener` | [Xem chi tiết](README_LAB_7.md) |
| 8 | Pizzeria | Firebase Authentication: đăng ký / đăng nhập / đăng xuất bằng Email + Password | [Xem chi tiết](README_LAB_8.md) |
| 9 | Inventory | Cloud Firestore: thêm, đọc, sửa, xóa mặt hàng | [Xem chi tiết](README_LAB_9.md) |
